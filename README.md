# 📊 Netflix Content Analysis Dashboard – Power BI

This project showcases an interactive Power BI dashboard built to analyze and visualize Netflix content data. The dashboard reveals trends in content distribution, popular genres, top-producing countries, and the evolution of content over time.

## 🔍 Project Highlights

- Cleaned and transformed raw Netflix data using **Power Query**
- Built dynamic measures and calculated columns using **DAX**
- Designed an interactive dashboard that includes:
  - Content distribution by **country**, **type** (Movie/TV Show), and **genre**
  - Release trends over the years
  - Most frequent content-producing countries
  - Filter and slicer options for deeper exploration

## 🧰 Tools & Technologies

- Power BI (Desktop)
- DAX (Data Analysis Expressions)
- Power Query
- Excel (initial data formatting)

## 📁 Files Included

- `Netflix.pbix` – Main Power BI project file
- `Screenshots/` – Folder containing high-quality images of the dashboard
- `README.md` – Project documentation (this file)

## 🎯 Objective

This project was developed to improve my skills in data cleaning, visualization, and storytelling through dashboards. It simulates a real-world scenario where content teams or business users need actionable insights for strategic decisions.

## 🚀 Get Started

To view or explore the dashboard:
1. Download the `Netflix.pbix` file
2. Open it in **Power BI Desktop**
3. Explore the visuals and try filtering by genre, country, or year
